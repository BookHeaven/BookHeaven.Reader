# Highlights and Notes
You can now select text in the reader, which allows you to highlight or copy it to the clipboard.  
To do this, just select the text you want and choose the appropriate option from the floating menu that will appear close to your selection:
- Highlight: will highlight the selected text.
- Note: will highlight the selected text while also adding a note to it.
- Copy: will copy the selected text to the clipboard.  

Long pressing on an existing highlight will allow you to edit it or delete it.  

It's also possible to select text across multiple pages.   
Just start selecting text, and when you are near the edge of the page, keep holding for a bit; the reader will automatically turn the page and you will be able to continue selecting text on the next page.  
It can be a bit tricky, but it can be done.

Then, on the reader's overlay, a new icon (which looks like a sticky note) will allow you to manage the list of all the highlights and notes for the opened book.  
Tapping on the highlight itself in that list (the bit with darker background) will take you to the page where it is located.
